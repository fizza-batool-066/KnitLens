# 🧶 KnitLens
## AI-Powered Crochet Progress Tracker and Smart Crafting Assistant

![KnitLens Banner](screenshots/banner.png)

## 📌 Overview

KnitLens is an AI-powered crochet assistant that combines Computer Vision and Multimodal Artificial Intelligence to help crochet enthusiasts analyze their projects, detect visible mistakes, track progress, and receive personalized guidance.

Unlike traditional crochet applications that only provide static patterns and tutorials, KnitLens understands the user's actual crochet work through image analysis and provides intelligent feedback.

The system uses YOLOv11 for crochet image detection and Alibaba Cloud Qwen for generating AI-powered crochet guidance.

---

# 🎯 Problem Statement

Crochet enthusiasts often struggle with:

- Tracking project progress
- Identifying mistakes early
- Understanding complex patterns
- Knowing the correct next steps

Small mistakes such as missing stitches or holes can remain unnoticed and may require users to undo hours of work.

Existing applications provide instructions but cannot analyze the user's actual crochet project.

KnitLens solves this problem by providing an intelligent AI assistant that understands crochet projects visually.

---

# 💡 Solution

KnitLens allows users to:

- Create crochet projects
- Upload crochet images
- Analyze projects using AI
- Detect crochet swatches and visible defects
- Receive personalized guidance
- Track project history and progress
